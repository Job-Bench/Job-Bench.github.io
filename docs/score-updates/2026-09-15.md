## Aggregation

Following `jobbench/eval/README.md`, overall scores are
`100 * sum(total_score) / sum(max_score)`, rounded to two decimal places.
Occupation scores use the same calculation within each occupation.
Rubric pass rates are `100 * sum(passed_count) / sum(total_count)`.
All 65 tasks are included, including tasks scoring zero.

These entries include the full occupation breakdown used by the heatmap.
Ranks and `totalModels` are regenerated for the 21-entry leaderboard.
