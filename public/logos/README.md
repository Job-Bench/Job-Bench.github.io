# Logo sources

The following icons were downloaded unchanged from the companies' official
websites on 2026-09-16 and are served locally at 18 × 18 CSS pixels.

| Local file | Source |
| --- | --- |
| `thinking-machines.png` | https://thinkingmachines.ai/images/favicon-32x32.png |
| `nvidia.png` | https://docs.nvidia.com/favicon-32x32.png |

The Thinking Machines chart color, `#0E9EE4`, uses the `--blue` accent from
[its website stylesheet](https://thinkingmachines.ai/css/common.css).
The NVIDIA chart color, `#76B900`, follows the green specified in
[its brand guidelines](https://www.nvidia.com/content/dam/en-zz/Solutions/about-us/documents/NVIDIA-Trademark-and-Logo-Usage-Guidelines.pdf).
